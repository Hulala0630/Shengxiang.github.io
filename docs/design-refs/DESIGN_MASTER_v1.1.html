双主题硬性规则（在 v1.0 十条之上追加）：
⑪ 主题唯一入口是 <html data-theme>；组件禁止硬编码颜色，只准引用 token。
⑫ 语义色 --run / --alarm / --ai 与 RUNTIME 屏内配色不随主题变化——运行永远绿、报警永远琥珀、AI 永远紫，两个主题下含义一致。
⑬ DESIGN 图纸是唯一"按主题重新诠释"的组件：LIGHT=白纸墨线，DARK=蓝晒图（--sheet-bg/--sheet-grid/--draw-* 六个 token 承载全部差异）。
⑭ 主题开关与 DESIGN/RUNTIME 开关共用同一造型语言（无圆角、mono 字体、active 反色填充），放在导航栏右侧，热区 ≥44px。
⑮ 生产实现：初始值跟随 prefers-color-scheme，用户选择写入 localStorage（键名 theme），并在 <head> 内联脚本中先于渲染读取以避免闪烁（本样板为演示环境，未含持久化）。
⑯ 主题切换过渡 0.35s，仅作用于 background/color/border；RUNTIME 上电过渡保持 0.45s，两者不共用。
⑰ 两主题均需通过 WCAG AA：正文对比度 ≥4.5:1（LIGHT: #17181A/#F5F5F2 ≈ 15:1；DARK: #E8E7E2/#141519 ≈ 13:1）。
